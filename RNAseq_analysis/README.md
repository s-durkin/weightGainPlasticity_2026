**10dayVadultLiver.R** contains analyses to compare 10-day liver gene expression to previously published adult liver gene expression (Ballinger et al. 2023). Figure 3G, Supplementary Figure 5.

**LIVERdefine_DE&ASE_comps.R** contains code to set up all differential expression and allele-specific expression datasets that are used in downstream analyses.

**LIVERdefine_cis_trans.R** contains code to determine regulatory categories from allele-specfic expression data and generate associated plots. Also includes code to analyze regulatory variation in genetic and maternally controlled sets of genes. Figure 2B-C, E. 

**LIVERmat_vs_gen.R** contains code to define maternally and genetically controlled expression variation.

**LIVERternary.R** contains code to determine the contribution of genetic, environmental, and GxE forces to expression variation and generate associated ternary plot. Figure 1F.

**NYBZvBZNY_regulatoryTypes.R** contains analyses to compare regulatory categories determined in reciprocal F1 hybrids and generate associated plots. Figure 2F.

**matLiver_WGCNA.R** contains code to perform WGCNA analysis in MANA maternally controlled genes and generate associated plots. Figure 3.
