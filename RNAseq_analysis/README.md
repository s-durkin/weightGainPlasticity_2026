**10dayVadultLiver.R** contains analyses for comparing 10-day liver gene expression to previously published adult liver gene expression (Ballinger et al. 2023). Figure 3G, Supplementary Figure 5.

**LIVERdefine_DE&ASE_comps.R** contains code for setting up all differential expression and allele-specific expression datasets that are used in downstream analyses.

**LIVERdefine_cis_trans.R** contains code for determining regulatory categories from allele-specfic expression data and generating associated plots. Also includes code to analyze regulatory variation in genetic and maternally controlled sets of genes. Figure 2B-C, E. 

**LIVERmat_vs_gen.R** contains code for defining maternally and genetically controlled expression variation.
